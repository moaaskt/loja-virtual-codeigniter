# Codebase Stack

## Core Technologies
- **Language**: PHP 8.1+
- **Framework**: CodeIgniter 4 (`codeigniter4/framework: ^4.0`)
- **Web Server**: Apache
- **Database**: MySQL 5.7

## Frontend
- **Markup**: HTML5
- **Styling**: CSS3, Bootstrap 5
- **Scripting**: JavaScript (Vanilla)

## Infrastructure
- **Containerization**: Docker & Docker Compose
- **Package Manager**: Composer

## Development Tools
- **Testing**: PHPUnit 10.5.16
- **Data Generation**: FakerPHP
